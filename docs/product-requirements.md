# プロダクト要件定義書

## プロダクトビジョン

**buntan**（分担）は、同居する家族やルームメイトなど小規模グループの家事分担を楽しくするiOSアプリ。タスクをこなしてポイントを獲得し、グループ内ランキングで競い合うことで、家事の不公平感を解消し継続的な参加を促す。

---

## ターゲットユーザー

- 家族・カップル・ルームメイトなど、同じ生活空間を共有する2〜10人程度のグループ
- スマートフォン（iPhone）を日常的に使う日本語ユーザー

---

## ユーザーストーリー

### セットアップ（初回起動）

| # | ストーリー |
|---|-----------|
| U-1 | 初回起動時に、ユーザー名を入力し、Firestore に登録済みのグループ一覧からピッカーで参加グループを選択してアプリを使い始めたい |

### グループ管理

| # | ストーリー |
|---|-----------|
| G-1 | グループ管理者として、グループ名（任意でパスワード付き）を作成して家族に招待したい |
| G-2 | メンバーとして、グループ名（とパスワード）を入力して既存グループに参加したい |
| G-3 | メンバーとして、参加中のグループを切り替えて複数グループを管理したい |

### タスク管理

| # | ストーリー |
|---|-----------|
| T-1 | グループ管理者として、グループ共有タスク（名前・ポイント）を追加したい |
| T-2 | グループ管理者として、グループ共有タスクを編集・削除したい |
| T-3 | メンバーとして、一覧からタスクを選択して「完了」を送信し、自分のポイントに加算したい |

### ランキング・ポイント

| # | ストーリー |
|---|-----------|
| R-1 | メンバーとして、グループ内の累計ポイントランキングをリアルタイムで確認したい |
| R-2 | メンバーとして、自分の累計ポイントをサイドメニューから確認したい |

### 履歴

| # | ストーリー |
|---|-----------|
| H-1 | メンバーとして、自分がこれまでこなしたタスクの履歴（名前・ポイント・時刻）を確認したい |

### チュートリアル

| # | ストーリー |
|---|-----------|
| P-1 | 初回起動時に、アプリの基本操作をチュートリアルで案内されたい |

## 受け入れ条件

### セットアップ（初回起動）

- 認証機能は現在実装されていない。アプリ起動時の Initial VC は `StartAppViewController`
- 初回起動時（`isSetup` が未設定）：ユーザー名入力 + グループピッカー選択 → `UserDefaults` に `User`・`Group` を保存 → `isSetup = true` → メイン画面へ
- 2回目以降の起動：`isSetup == true` を検知してセットアップをスキップし、直接メイン画面（`TabBarController`）へ遷移
- `LoginViewController` / `SignupViewController` は storyboard 上に存在するが、現時点では動線がなく未使用

### グループ

- グループ名は Firestore の `group` コレクションのドキュメントIDとして一意に管理する
- パスワードは任意。設定する場合は半角英数字5文字以上
- 現在参加中のグループ名は `UserDefaults` の `Group` キーで保持する

### タスク

- グループ共有タスクは Firestore の `task` コレクションで管理（`group`・`name`・`point` フィールド）
- 個人タスク履歴は Realm の `TaskItem` オブジェクト（`taskId`・`name`・`point`・`time`）でオフライン保持
- タスク完了時：Realm に履歴を書き込み → Firestore の `users` コレクションに累計ポイントを送信

### ポイント・ランキング

- ポイントは Firestore `users` コレクションの `point` フィールドで管理
- `sendDoneTask` 呼び出し時に累計ポイント（Realm 合計）で上書きする
- ランキングはポイントの降順で表示し、リアルタイムリスナーで自動更新する

## 機能要件

| 優先度 | 機能 |
|--------|------|
| Must | 初回セットアップ（ユーザー名・グループ選択） |
| Must | グループ作成・参加・切り替え |
| Must | グループタスクの追加・編集・削除（Firestore） |
| Must | タスク完了送信とポイント加算 |
| Must | グループ内ランキング表示（リアルタイム） |
| Must | 個人タスク履歴表示（Realm） |
| Should | 初回チュートリアル表示 |
| Should | サイドメニューでのポイント・ユーザー名確認 |

---

## 非機能要件

| 項目 | 要件 |
|------|------|
| 対応 OS | iOS 18.0 以上 |
| 言語 | 日本語 UI |
| オフライン | 個人タスク履歴は Realm でオフライン参照可能 |
| リアルタイム性 | Firestore リスナーによるランキング・タスクのリアルタイム同期 |
| セキュリティ | グループにパスワードを設定可能（任意） |
| パフォーマンス | タスク一覧・ランキングは通常のネットワーク環境で3秒以内に表示 |
