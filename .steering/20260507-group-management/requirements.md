# Requirements: グループ退会・削除機能

## 概要

グループ管理機能を追加する。現在はグループの切り替えしかできないため、退会・削除の手段がない。

---

## ユーザーストーリー

- **US-1 退会:** グループメンバーとして、自分がグループを退会できる。退会するとランキングから除外され、初期設定画面へ戻る。
- **US-2 グループ削除:** グループの代表者として、グループ自体を削除できる。削除するとグループのタスク・メンバー情報がすべて消え、自分は初期設定画面へ戻る。
- **US-3 自動リダイレクト:** 所属グループが他のメンバーに削除された場合、次回アプリ使用時（またはリアルタイムで）自動的に初期設定画面へ戻る。

---

## 受け入れ条件

### 退会（US-1）
- [ ] SettingsView に「グループを退会する」ボタンが表示される
- [ ] ボタンタップ後に確認アラートが表示される
- [ ] 確認後、Firestore の `users/{userName}` ドキュメントが削除される
- [ ] Realm の全 TaskItem（タスク履歴）が削除される
- [ ] UserDefaults の `isSetup`, `currentUser`, `currentGroup`, `isShowTutorial` がリセットされる
- [ ] StartAppView（初期設定画面）へ自動遷移する

### グループ削除（US-2）
- [ ] SettingsView に「グループを削除する」ボタンが表示される（警告文付き）
- [ ] ボタンタップ後に強い警告を含む確認アラートが表示される
- [ ] 確認後、Firestore の `task` コレクション内の当該グループのタスクがすべて削除される
- [ ] Firestore の `group/{groupName}` ドキュメントが削除される
- [ ] 実行者自身の `users/{userName}` ドキュメントが削除される
- [ ] 退会と同様にローカルデータ全削除 → StartAppView へ遷移する

### 自動リダイレクト（US-3）
- [ ] MainTabView 表示中、Firestore の `group/{groupName}` ドキュメントを監視する
- [ ] グループドキュメントが削除されると、退会と同じクリーンアップが自動実行される
- [ ] StartAppView へ自動遷移する

---

## 制約

- 新しい外部ライブラリは追加しない（Firebase SDK の既存 API のみ使用）
- 「グループオーナー」概念は現状存在しないため、誰でも削除可能とする
- グループ削除時に他メンバーの `users/{name}` ドキュメントは削除しない（他端末は自動リダイレクト後に再セットアップで上書きされる）
- タスク削除順序：`task` → `group` の順（グループ削除後にタスク削除しようとすると意図しない動作を防ぐため）
