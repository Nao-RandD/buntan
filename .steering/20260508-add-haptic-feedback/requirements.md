# Requirements: Haptic Feedback の追加

## 概要

タブ切り替え・メニュー表示・タスク送信の3箇所に Haptic Feedback を追加し、アプリの操作感（触覚的フィードバック）を向上させる。

## ユーザーストーリー

- **U-HF-1:** ユーザーがタブを切り替えたとき、軽いバイブレーション（セレクション）を感じることで、操作が確実に認識されたことを体感できる
- **U-HF-2:** ユーザーがメニューを開いたとき、軽いインパクトフィードバックにより、シートが表示されることを事前に体感できる
- **U-HF-3:** ユーザーがタスクを送信して完了したとき、成功フィードバックにより達成感を得られる

## 受け入れ条件

- [ ] タブを「ホーム」↔「ランキング」で切り替えるたびに `.selection` フィードバックが発火する
- [ ] ハンバーガーメニューボタンをタップしてメニューシートが開くとき `.impact(weight: .light)` フィードバックが発火する（閉じるときは発火しない）
- [ ] タスクを選択して送信が完了したとき `.success` フィードバックが発火する（アラート非表示時には発火しない）
- [ ] ビルドエラーなし

## 制約

- iOS 18.0+ を対象とするため SwiftUI ネイティブの `.sensoryFeedback` modifier を使用する（`UIFeedbackGenerator` は使用しない）
- `DashboardView` は MenuView を表示しないため変更対象外
- `docs/` の変更は不要（アーキテクチャ・データモデルへの影響なし）
