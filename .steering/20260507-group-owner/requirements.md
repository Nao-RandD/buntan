# Requirements: グループオーナー機能

## 概要

グループ作成者を「オーナー」として管理し、権限の差別化とオーナー専用の管理機能を追加する。

---

## ユーザーストーリー

- **US-1 オーナー記録:** グループを作成したユーザーが自動的にオーナーになる。
- **US-2 オーナーマーク:** ランキング画面でオーナーには王冠アイコンが表示される。
- **US-3 削除権限制限:** グループの削除はオーナーのみが実行できる。非オーナーには削除ボタンを表示しない。
- **US-4 グループ名変更:** オーナーはグループ名を変更できる。変更時は非オーナーメンバーが初期設定画面へリダイレクトされ、新しいグループ名で再参加する必要がある。
- **US-5 パスワード変更:** オーナーはグループのパスワード設定（有無・値）を変更できる。

---

## 受け入れ条件

### オーナー記録（US-1）
- [ ] `addGroup` 時に Firestore の `group/{name}` ドキュメントに `owner: String` フィールドを保存する
- [ ] `owner` はグループ作成者のユーザー名（`currentUser`）とする

### オーナーマーク（US-2）
- [ ] ランキング画面でオーナーのユーザー名の横に王冠アイコン（`crown.fill`）が表示される
- [ ] 自分がオーナーでない場合も、オーナーのユーザーに王冠が表示される

### 削除権限制限（US-3）
- [ ] 設定画面の「グループを削除する」ボタンはオーナーのみに表示される
- [ ] 非オーナーにはボタン自体が非表示になる

### グループ名変更（US-4）
- [ ] 設定画面にオーナー専用セクションが表示される（非オーナーには非表示）
- [ ] グループ名変更フォームで新しいグループ名を入力できる
- [ ] 変更確認アラートに「メンバーは再ログインが必要になります」の警告を含める
- [ ] 変更後、Firestore の task・users ドキュメントの group フィールドが新名称に更新される
- [ ] 変更後、オーナーのアプリは新グループ名でそのまま継続して使用できる
- [ ] 非オーナーメンバーは削除検知により初期設定画面へ遷移する

### パスワード変更（US-5）
- [ ] オーナー設定画面でパスワードの有無を切り替えられる
- [ ] パスワードを設定する場合、既存のバリデーション（半角英数字5文字以上）を適用する
- [ ] 変更後、他のメンバーがグループ参加時に新パスワードが要求される

---

## 制約

- 新しい外部ライブラリは追加しない
- `owner` フィールドがない既存グループは `isGroupOwner == false` として扱う（オーナー機能の対象外）
- グループ名変更時に非オーナーが強制ログアウトされることは許容する（UI で明示的に警告する）
- グループ名変更後も非オーナーの `users/{name}` ドキュメントは残る（再参加時に上書きされる）
